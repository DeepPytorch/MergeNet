# MergeNet
MergeNet is a type of InceptionResnet with 7 variants: Nano, Micro, Mini, Small, Standard, Large, and Mega.
<br>
MergeNet uses Inception layers along with a skip connection for each layer. 

| Name | # Layers| Parameter Count |
| -------- | -------- | -------- |
| Row 1, Col 1 | Row 1, Col 2 | Row 1, Col 3 |
| Row 2, Col 1 | Row 2, Col 2 | Row 2, Col 3 |
